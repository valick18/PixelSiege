# Pixel Siege (prototype) - Godot 4.3+

## EXE
1. Install Godot 4.3+ (standard) and its Export Templates (Editor > Manage Export Templates > Download).
2. Run `build_exe.bat` (set GODOT=path\to\godot.exe if godot is not in PATH).
3. Result: `build\PixelSiege.exe` (single file, no install needed).
Or just run `run_game.bat` / open the folder in Godot and press F5.

## Multiplayer
- Host: Host game. LAN servers appear automatically in the list. The host tries UPnP to open UDP 24565 automatically
  (the public address is shown top-left in game). If the router blocks UPnP, forward UDP 24565 manually.
- Test on one PC: Debug > Customize Run Instances > Enable Multiple Instances.

## Controls
WASD move, Space jump, Shift run, Ctrl crouch, LMB use item / dig, RMB attack, X block (tap right before a hit = parry), Z dodge,
Q class ability, 1-0 select slot, E use medkit/food or fire a catapult, R deposit / G take from team storage (at base flag or storage chest),
C crafting, F1-F4 class (near own base or when dead), Esc menu (settings, leave).
Movement keys can be rebound in Settings.

## Music
Put .ogg/.mp3/.wav files into assets/music - the first one loops automatically.

## Art
All sprites are generated by `tools/make_art.py` (Python + Pillow): blocks atlas, items, 4 classes x 2 teams x 22 animation frames,
flags, parallax mountains, clouds, logo, icon. Edit and re-run it, or replace the PNGs in `assets/` with your own (keep sizes).

## One-click build
Put the Godot executable into the `_tools` folder, then run `build_exe.bat` (export templates must be installed once).

## Art
`python tools/build_art.py` (needs Pillow) regenerates all art: autotiled terrain with rounded edges and grass,
underground back walls, tree sprites, 4 parallax layers (mountains, hills, forest), dithered sky, clouds, sun/moon/stars,
characters, items, fire/explosion/slash effects. Everything is drawn at 1 texel = 1 world pixel, camera zoom x2.
