# PixelSiege: оновлення v6 (виправлення вікна крафту)

Причина "порожнього" крафту: нижній текст вікна (Label з переносом рядків) не мав мінімальної ширини.
На першому кадрі його ширина 0, тому кожна літера переносилась на новий рядок, висота ставала величезною,
вікно розтягувалось на весь екран, а заголовок, вкладки і рецепти опинялись за межами екрана.

Виправлено:
- `scripts/ui/craft_ui.gd`: текст отримав мінімальну ширину, вікно при відкритті стискається до вмісту і стає по центру.
- `scripts/game.gd`: будь-яке вікно (крафт, інвентар, команда, клас, пауза) при відкритті стискається до свого розміру й центрується.

Встановлення: скопіюйте вміст папки `PixelSiege/` поверх репозиторію із заміною файлів.
